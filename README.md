
# nmixx-twitter-feed

A simple and responsive webpage that displays real-time tweets from NMIXX Official and WE_NMIXX Twitter accounts. Features include a dark mode toggle, smooth scrolling, and an optimized Twitter widget load time.

## 🚀 Features
- 📡 **Live Twitter Feeds** – Fetches and displays tweets from @NMIXX_official and @WE_NMIXX.
- 🌙 **Dark Mode** – Toggle between light and dark mode with smooth transitions.
- 🎨 **Responsive Design** – Optimized for both desktop and mobile.
- ⏳ **Delayed Twitter Widget Load** – Improves page speed by loading the Twitter widget after the page is rendered.
- 🛠️ **Custom Styling** – Clean UI with smooth animations and a professional layout.
